# Security policy

Please **do not open public issues** for security problems. Report them privately via
[GitHub Security Advisories](../../security/advisories/new) of this repository.

Include steps to reproduce, affected platform(s) and version. You will get a reply within a few days.

Supported: the latest release.

---

Об уязвимостях сообщайте **приватно** через GitHub Security Advisories этого репозитория, а не в публичных issues.
